Odyssey is an offline audio guide for ancient places: each stop has one human narration, and numbered markers on the main photograph open a silent museum label with the picture, a short text, and a clear evidence tag. The interface follows Apple’s Human Interface Guidelines, uses a single terracotta accent (`#E05D34`) on a light surface, and keeps navigation to two tabs so a visitor can walk a curated route without a network connection and later use the same stops for interactive tourism education.
